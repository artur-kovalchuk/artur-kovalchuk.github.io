Privacy Practices Certification

This document outlines how the Chrome Extension Toolbar Icon Previewer handles user data and confirms compliance with Google's Developer Program Policies.

Developer Certification

I hereby certify that this extension's data usage complies with Google Chrome Web Store's Developer Program Policies, including but not limited to:

  • User Data Privacy requirements
  • Limited Use requirements
  • Personal and Sensitive User Data Policy

This extension is designed with user privacy as a priority and only collects the minimum data necessary for its core functionality.

Data Usage & Collection

What data does this extension collect?

This extension collects:

  • User-uploaded images (icons) - These are stored locally in Chrome's storage API and are never transmitted to external servers
  • UI preferences - User interface settings such as border visibility and border color preferences

How is this data used?

The collected data is used exclusively for:

  • Providing the core functionality of previewing custom icons in the Chrome extension toolbar
  • Remembering user interface preferences between sessions
  • All data stays on the user's device and is stored using Chrome's built-in storage API

Data sharing and third parties

This extension:

  • Does not transmit any user data to external servers
  • Does not share any data with third parties
  • Does not use any analytics or tracking services
  • Does not include any advertisements or monetization features

User Rights and Controls

Users have complete control over their data:

  • All data is stored locally and can be cleared by resetting the icon or by clearing browser data
  • Uninstalling the extension will remove all stored data
  • No user account or registration is required to use this extension

Chrome API Usage

This extension uses the following Chrome APIs:

  • chrome.storage - To store user-uploaded icons and UI preferences
  • chrome.action - To update the extension's toolbar icon
  • chrome.runtime - For background script communication
